# AxolotlClient-Fork

Fork of https://codeberg.org/AxolotlClient/AxolotlClient-mod, focused on **Minecraft 1.8.9 (Ornithe)** and Hypixel.

Open the client menu in-game with **Right Shift**.


To build:

```
./gradlew build
```
